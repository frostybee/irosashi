From an empty project to highlighted, decorated code blocks, in Rust or from the terminal.

- [Installation](/docs/getting-started/installation) adds `irosashi` and `kazari-rs` to a
  project, or installs the `kazari` binary.
- [Quick start](/docs/getting-started/quick-start) creates a highlighter, reads tokens, and
  renders single-theme, dual-theme, and class-based HTML.
- [Decorated code blocks with Kazari](/docs/getting-started/kazari) adds frames, line
  numbers, markers, a toolbar, Typst output, and Markdown rendering.
- [Command line](/docs/getting-started/cli) upgrades a built static site or renders files
  with the `kazari` binary, with no Rust code.
