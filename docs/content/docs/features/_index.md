What Irosashi produces from one tokenization, and how to drive it line by line.

- [Output formats](/docs/features/output-formats) covers HTML in two dialects, ANSI, SVG,
  JSON, plain text, and raw tokens.
- [Per-line tokenization](/docs/features/per-line-sessions) covers the `Session` API with
  explicit state handles, for editors and previews that re-tokenize from a dirty line.
- [Runnable examples](/docs/features/examples) lists the example programs in the
  repository, one feature each.
