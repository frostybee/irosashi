# Kazari brand assets

Master copies of the Kazari logo and favicon for the Rust crate. They are byte-identical to
the Go Kazari masters in that repository's `brand/` folder: `kazari-rs` is the same product on
a different engine, so it carries the same mark. Edit the Go masters first and copy them here.

| File | Used by |
|------|---------|
| `kazari-logo.svg` | `README.md` header image. 512-unit canvas, built for 160 px and up. |
| `kazari-favicon.svg` | Favicon and small header marks (16 to 40 px). Redraws the K as three plain strokes and drops the dots, rule and code lines, which fall below one pixel at that size. |

Palette (from `kazari-logo.svg`): panel `#23243A` to `#171821`, divider `#353650`, ribbon
cyan `#43C6D9` to violet `#7C5CFC` to pink `#FF6B81`, amber dot `#F7C85E`, K stem `#F5F3FF`.
