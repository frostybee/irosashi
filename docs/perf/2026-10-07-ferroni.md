# Performance on Ferroni 1.9.0 (2026-10-07)

Raw dumps behind the tables in README.md and docs/content/docs/why-irosashi.md, all taken in
one session on an idle machine: Criterion (irosashi-fidelity, `cargo bench --bench highlight`),
the `cold_start` test, `tools/shiki-bench` (Shiki 4.4.3), and `tools/kazari-bench` (release
`kazari` 0.2.0, both engines). Inputs and method are unchanged from
`2026-09-16-per-pattern.md`; only the regex engine changed (Ferroni 1.9.0 for `onig_sys`).
Machine: Intel Core i9-10850K, Windows 10, rustc 1.94.0 (4a4ef493e), Ferroni 1.9.0, Shiki 4.4.3, Node 24.12.0, theme `github-dark`.
